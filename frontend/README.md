# Brain MRI AI – Frontend

Modern premium SaaS-style React frontend for brain tumor classification.

## Requirements

- Node.js 18+
- Running API backend on `http://127.0.0.1:8000`

## Setup

```bash
cd frontend
npm install
npm run dev
```

Runs at `http://localhost:3000`. API calls are proxied to the backend.

## Build

```bash
npm run build
npm run preview
```

## Design Features

- Dark theme with animated gradient background
- Glassmorphism cards
- Gradient buttons and badge
- Inter font, smooth transitions
- Animated loading spinner
- Smooth confidence progress bar
- Fade-in results animation
- Responsive layout
