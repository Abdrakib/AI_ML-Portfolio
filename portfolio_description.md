# Brain MRI AI — Portfolio & Resume Content

## Professional Project Summary (3–4 sentences)

Brain MRI AI is a production-ready full-stack application that classifies brain tumor presence from MRI images using deep learning. Built with a FastAPI backend and React frontend, it features Grad-CAM explainability for transparent AI decisions, confidence-based uncertain prediction handling, and robust image validation. The application is deployed on Render (backend) and Vercel (frontend), demonstrating end-to-end ML pipeline deployment and MLOps practices.

## Interview Explanation (simple version)

"This project classifies brain MRI images for tumor detection. I took a trained model, wrapped it in a FastAPI backend, and built a React frontend for upload and visualization. The model uses Grad-CAM so we can see which regions influenced the prediction. I added validation for image format and size, and when confidence is low, we return 'Uncertain' instead of a binary answer. Everything is deployed: the API runs on Render and the frontend on Vercel."
